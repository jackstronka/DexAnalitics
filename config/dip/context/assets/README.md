# Asset journals (kompendium)

Każdy asset = folder `ID/`:

| Plik | Treść |
|------|--------|
| `meta.yaml` | status, tier, last_* timestamps |
| `thesis.md` | dlaczego na radarze |
| `journal.md` | ticki monitora + decyzje |
| `news.md` | **trwała baza newsów** — tylko dopisywanie |

Zasada: **zanim** WebSearch/XSearch dla assetu → przeczytaj `news.md`.

Tworzenie nowego: skopiuj strukturę z `SOL/` i dodaj mint do `config/mints.yaml` + wpis universe/watchlist.
